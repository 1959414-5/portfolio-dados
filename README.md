# portfolio-dados

Portfólio técnico de Bárbara Cabral Paschoalin para vagas de Analista de Dados Júnior, Analista de BI e Power BI.
Site estático (HTML, CSS e JavaScript puro), publicado com GitHub Pages: https://1959414-5.github.io/portfolio-dados/

## Estrutura
- `index.html`: apresentação, competências, projetos em destaque e contato
- `projetos/`: índice de projetos e uma página por projeto (projeto real: `projeto-real-pcp-comercial.html`)
- `assets/`: `css/`, `js/`, `img/` (capturas de tela) e `docs/` (currículo em PDF)

## Como testar localmente
Abra `index.html` no navegador, ou rode `python -m http.server` na pasta e acesse http://localhost:8000.

## Dados
Nenhum dado confidencial é publicado. Imagens de projetos reais são tratadas; estudos demonstrativos usam dados 100% sintéticos.
